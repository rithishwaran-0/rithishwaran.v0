Friends Mirror 1.0

Developers: Rithishwaran, Mahadeesh

Friends Mirror is a private chat for NVDA users. Calls are not included.

Getting started

  1. Press NVDA+Alt+C, or open the NVDA menu, Tools, Friends Mirror.
  2. Type a user name and a password and press Sign in. A new user name creates your account automatically. Use the same name and password on every computer. Your password creates your encryption keys, so it cannot be reset.
  3. Choose New chat and type your friend's user name. Your friend does the same with yours. The first message from a stranger arrives as a message request that you can accept, block or delete.
  4. Type your message and press Enter. Press Enter on a message in the list for message actions.

AI and advanced tools

First open Settings, AI settings and choose your AI provider (Google Gemini has a free plan) and API key.

  • In a chat, press AI and chat tools: suggest replies, rewrite your message (polite, shorter, fix grammar, translate), write a message from an idea, summarize the chat, catch up on unread messages, ask AI a question about the chat, quick replies, send later, read the last messages aloud, chat statistics.
  • On a message (Enter): translate, explain, suggest replies, read aloud, open or summarize a link, describe a picture, write down a voice message, remind me later.
  • In the chat list: AI assistant, catch up on all unread chats, read all unread messages, new reminder, scheduled messages, quick replies, export all chats, back up and restore.
  • Settings: AI settings and automatic translation of incoming messages, quiet hours, auto reply, keyword alerts, app lock with a password.

Keys

  • NVDA+Alt+C: open Friends Mirror.
  • NVDA+Alt+L: repeat the last message that was read aloud.
  • NVDA+Alt+U: say how many unread messages you have.
  • In a one to one chat: F5 says whether your friend is online and when they came online, or when they were last seen.
  • In a message list: Enter for message actions, Delete to delete for yourself, Control+C to copy.
  • Escape cancels a reply or a voice recording, and otherwise closes the window.

What is included

  • One-to-one chats and groups (admins, add and remove members, change name and description, leave).
  • Reply, forward, copy, edit (15 minutes), delete for me, delete for everyone, star, react with emojis, message info.
  • Sent, delivered and read marks, typing indicator, online status and last seen, with privacy switches.
  • Files and pictures up to 10 MB, voice messages, polls, shared contacts.
  • Status updates that last 24 hours.
  • Broadcast lists, disappearing messages, mute, pin (up to 3), archive, mark as unread, clear, delete and export chats.
  • Search inside a chat and in all chats, starred messages list.
  • Block and unblock, message requests, contact names of your own, safety numbers.
  • Your name, about text, sounds, read-aloud choices and more in Settings.

Privacy and limits

Messages, files and voice messages are encrypted on your computer; only the people in the chat can read them. Compare the safety number in the contact info with your friend to be sure that nobody listens in. If a contact's security key changes, Friends Mirror warns you and blocks the new key until you trust it.

Friends who are offline receive messages for about 12 hours and files for about 3 hours. Chats are stored on your computer only, and there is no cloud backup.

Not included: calls, stickers and GIFs, live location, status with pictures or video, channels and communities, linked devices, view-once media and payments.
